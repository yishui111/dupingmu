# 文字驱动器规则文件（每行一条规则，用 | 分隔，支持 # 注释）
# 格式：触发文字|命中指令|关闭指令|延时秒|画面关键词
# 触发文字：屏幕 OCR 文字包含它即命中；命中后发送“指令前缀+命中指令”，
#           延时秒后发送“指令前缀+关闭指令”（延时为0或不填关闭指令则不发送）
# ★ 修改话术方法：直接改本文件（记事本打开），保存后在程序里点“重新加载规则文件”即可
# ★ 也可以：程序“文字驱动器”页签 → 选中规则 → 编辑规则 修改
# 开关对应：1号=灯(GPIO14) 2号=风扇(GPIO11) 3号=空调(GPIO10) 4号=电视(GPIO8)
#           5号=电脑(GPIO1) 6号=热水器(GPIO0) 7号=窗帘(GPIO7) 8号=水泵(GPIO6)
# 延时说明：礼物出现→开，N 秒后自动关（直播刷礼物常用）；改成 0 则一直亮着等关闭话术
