# 屏幕文字识别监控 · 文字驱动器 · DeepSeek 视觉

一个绿色便携的屏幕文字工具，包含三大功能：

**一、屏幕文字监控**：框选屏幕上的一个区域，程序自动识别该区域内的文字，当文字**发生变化**时，把新文字自动写入一个记事本（txt）文件。OCR 完全离线。

**二、文字驱动器**：配置“屏幕文字 → 指令”规则，当屏幕出现指定文字时，自动通过**串口或网络（TCP）**给 ESP32 等设备发送指令；每条规则还可以设置延时多少秒后自动发送“关闭”指令（比如开灯 5 秒后自动关灯）。

**三、DeepSeek 视觉**：把截图发给 DeepSeek 视觉模型“看懂”画面（描述内容、识别画面关键词触发指令），弥补纯 OCR 认不出图形的短板（需联网 + API Key）。

## 功能特点

- 🖱️ 运行后点击“框选区域”，用鼠标拖拽即可框选要监控的屏幕区域
- 🔒 **离线 OCR**：RapidOCR（PP-OCR 模型 + ONNX Runtime），模型随程序一起打包，不联网、不上传任何数据
- 📝 区域**出现新文字**时，只把新增内容（带时间戳）追加写入 `屏幕文字记录.txt`：已出现的旧文字滚动/重复不会重记，OCR 半帧/抖动自动过滤；「确认轮数」可调（1=出现即记），还可勾选**按日期分文件**（每天一个新 txt，长期挂机不怕单个文件过大）
- ⚡ **文字驱动器**：屏幕文字命中规则后，自动发指令给 ESP32（串口/TCP），支持定时自动发送“关闭”指令；触发需连续 2 轮命中（防 OCR 抖动重复发），串口全程保持连接（不会反复开关串口复位 ESP32），画面静止时到期的关闭指令也会准点发送
- 👁️ **DeepSeek 视觉**：变化时自动"看图说话"写日志，规则可按画面关键词智能触发
- 💾 记住上次框选的区域、识别间隔、接口设置和规则，下次启动直接用
- 🔁 **单实例运行**：重复启动会弹窗提示并退出，不会出现两份监控同时写记录、抢串口
- 📦 **便携免安装**：打包后的整个文件夹复制到任何 Windows 电脑即可双击运行，无需安装 Python

## 使用方法（打包版，推荐）

1. 打包（见下方“如何打包”），或直接使用 `dist\屏幕文字识别监控\` 文件夹
2. 把 `dist\屏幕文字识别监控\` 整个文件夹复制到任意 Windows 电脑
3. 双击 `屏幕文字识别监控.exe`
4. 点击 **框选区域** → 在屏幕上按住鼠标左键拖拽，框住要监控的文字区域，松开完成
5. 设置识别间隔（秒，可填 0.5，评论区建议 0.5~1）和**确认轮数**（新文字连续出现几轮才落盘，默认 2；弹幕闪现太快漏记就改成 1），点击 **开始监控**
6. 当区域内**冒出新的文字**（如网友新打的字）时，只把新增部分（带时间戳）写入程序同目录下的 `屏幕文字记录.txt`（勾选“按日期分文件”则为 `屏幕文字记录_年-月-日.txt`）；画面没变化时几乎不耗 CPU

## 文字驱动器（如何控制 ESP32）

> ESP32 和电脑连**同一个 WiFi** 即可，无需数据线。ESP32 端固件在 `esp32\` 文件夹里（Arduino IDE 打开烧录，详见 `esp32\README.md`）。

1. 切到 **文字驱动器** 页签
2. 点 **添加规则**，填写：
   - **触发文字**：屏幕出现这个文字就命中（如 `打开灯`）
   - **命中指令**：命中后立即发送的指令码（如 `001on`）
   - **关闭指令**：延时后发送的指令码（如 `001off`，可留空）
   - **延时（秒）**：命中后多少秒发送关闭指令（`0`=不发送）
3. 设置**发送接口**：
   - 发送方式：`serial`（USB 串口连接 ESP32）或 `tcp`（**WiFi 连接，推荐**）
   - 串口：COM 口号 + 波特率（默认 115200）；程序会保持串口常驻连接，不会反复开关串口导致 ESP32 复位
   - 网络：主机填 ESP32 的 IP（烧录后串口监视器会打印，或填 `esp32.local`）+ 端口 8085
   - **指令前缀**（默认 `001`）：发送内容 = 前缀 + 指令码，例如前缀 `001` + 命中指令 `001on` → 实际发送 `001001on`，ESP32 解析 `001on` 控制 1 号开关打开
   - 指令后缀：可加 `\r\n` 等结束符（界面输入 `\r\n` 会自动转成回车换行），默认空
4. 点 **保存接口设置**，然后开始监控；屏幕文字命中规则时会自动发指令
5. 每次发送会记录到 `指令发送记录.txt`，方便核对

> 命中判定要求触发文字**连续 2 轮** OCR 都出现（防抖动，避免识别抖动导致重复发指令）；“延时秒”到点就发关闭指令，即使画面静止也会准点发送。

> 规则也可以直接用记事本编辑程序目录下的 **`指令规则.txt`**（每行一条，格式：`触发文字|命中指令|关闭指令|延时秒|画面关键词`，`#` 开头是注释），编辑后点“重新加载规则文件”。

## DeepSeek 视觉理解（联网，需 API Key）

第三个页签 **DeepSeek 视觉**，让程序"看懂"画面而不只是认字：

1. 在 [api.deepseek.com](https://api.deepseek.com) 申请 API Key，填入 **API Key** 一栏
2. 勾选 **启用 DeepSeek 视觉理解**
3. 点 **识别当前区域并描述** 可立即测试：程序截图框选区域 → 发给 DeepSeek 视觉模型 → 显示并写入 `屏幕画面描述.txt`
4. 勾选 **屏幕文字变化时自动调用** 后，监控期间区域文字一变化就会自动描述画面

**智能指令匹配**：规则里的 **画面关键词**（第五个字段）如果出现在视觉描述文本中，同样会触发指令。适合"认不出文字、但看得出画面"的场景，例如：

```
触发文字|画面关键词|命中指令|关闭指令|延时秒
        |风扇      |003on   |003off  |10
```

> 说明：视觉理解需要联网；模型默认 `deepseek-v4-pro`（识图模型），以官方实际模型名为准，调不通时看 `程序错误日志.txt` 里的报错。API Key 会明文存在本地 `config.json` 里，注意文件夹保密。

## 如何打包成 exe

在装有 Python 的电脑上，双击 `build.bat`（首次需要联网下载依赖，之后可离线打包）：

- 打包产物在 `dist\屏幕文字识别监控\` 文件夹中
- 把整个文件夹复制到任何 Windows 电脑即可直接使用，**目标电脑不需要装 Python、不需要联网**

## 源码运行（开发者方式）

```bat
py -3.12 -m venv .venv                                          :: 首次：创建虚拟环境
.venv\Scripts\pip install -r requirements.txt                    :: 首次：安装依赖
.venv\Scripts\pythonw main.py
```

也可以直接双击 `启动(源码).bat`（脚本会自动优先使用项目内的 `.venv`，没有时才回退到系统 pythonw）。

命令行自检（不弹窗，验证离线 OCR 是否可用）：

```bat
python main.py --selftest
```

## 常见问题

**1. 杀毒软件误报？**
PyInstaller 打包的程序偶尔会被某些杀毒软件误报，添加信任即可。本程序完全本地运行，不联网、不含任何恶意行为。

**2. 识别不准？**
- 尽量框选干净、清晰的文字区域，不要包含太多背景
- 提高屏幕分辨率 / 放大字体后识别率更高
- 可以点击“立即识别一次”先测试效果

**3. 框选时只支持主屏幕？**
框选遮罩显示在主屏幕。多显示器用户可以先把窗口拖到目标显示器再框选（遮罩会覆盖主屏）。

**4. 为什么第一次点“开始监控”会卡几秒？**
首次加载 OCR 模型需要几秒钟，之后每次识别都很快。

**5. 识别不到文字 / 好像没反应？**
- 先点“立即识别一次”测试当前框选的区域：能识别说明没问题，识别不到会提示“（区域内未识别到文字）”
- 确认框选的区域里确实有文字（框住整个文字区域，别只框一半）
- 检查状态栏是否提示出错；如果程序内部出错，会自动写入程序同目录的 `程序错误日志.txt`，把里面的内容发给我即可定位

**6. 高分屏 / 系统缩放（125%、150% 等）导致框选错位？**
新版已自动适配：框选时程序会把坐标换算成屏幕物理像素，任何缩放比例下都能对齐，无需手动设置。

**7. 目标电脑提示缺少 DLL？**
打包后的文件夹已自带运行库；如果仍然报错，请在目标电脑安装一次微软 VC++ 运行库（搜索“VC_redist.x64”下载安装）即可。

**8. 识别间隔设多少合适？**
文字变化频率低建议 2–5 秒；需要快速响应可以设 1 秒。

**9. 明明出现的文字没有被记录？**
新文字默认要**连续 2 轮识别都出现**才写入记录（用于滤掉 OCR 半帧/抖动垃圾）。如果文字只闪现一瞬间（比如快速滚过的弹幕），把“设置”里的**确认轮数**改成 1，就是出现即记。

**10. 双击了两次启动脚本 / 提示“已经在运行”？**
程序同一时间只允许运行一份：重复启动会弹窗提示并自动退出，避免两份监控同时写记录、抢串口。要重启请先关闭已有窗口（或运行 `stop.bat`）再启动。
