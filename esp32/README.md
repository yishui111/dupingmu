# ESP32 端固件（开关控制器 · WiFi 配网版）

让 ESP32 连上家里的 WiFi，作为 TCP 服务器接收电脑端程序发来的指令，控制继电器开关。

**亮点：不用改代码填 WiFi！** 第一次上电时 ESP32 自己开一个热点，手机连上后配网页面自动弹出，填一次 WiFi 名和密码，以后开机自动连接，换 WiFi 也不用重新烧录。

## 文件

- `esp32_switch/esp32_switch.ino` —— 固件源码（Arduino IDE 直接打开）

## 工作流程

```
电脑屏幕出现"打开灯" → 电脑端程序识别 → TCP 发送 001001on
                                              ↓
                    ESP32 解析 001on → 1号开关（GPIO32）吸合，灯亮
                    5 秒后电脑端再发 001001off → 灯灭
```

指令格式：`设备号(3位) + 开关号(3位) + on/off`，例如：

| 指令 | 含义 |
|------|------|
| `001001on` | 设备001 的 1号开关 打开 |
| `001001off` | 设备001 的 1号开关 关闭 |
| `001002on` | 设备001 的 2号开关 打开 |
| `001on`（简写） | 任意设备 1号开关 打开 |

## 使用步骤（只烧录一次）

1. **烧录**：Arduino IDE 打开 `esp32_switch.ino` → 工具 → 开发板选 **ESP32 Dev Module** → 端口选 ESP32 的 COM 口 → 点 **上传**（连不上就按住 **BOOT** 键再点上传）
2. **配网**：手机/电脑搜 WiFi，连接热点 **`ESP32-Switch-Config`**（无需密码）
3. **填 WiFi**：浏览器会自动弹出配网页面（没自动弹就手动打开 `http://192.168.4.1`），选择你家 WiFi、输入密码 → 点 **保存并连接**
4. **完成**：ESP32 自动重启并连上你家 WiFi（热点自动关闭），打开串口监视器（115200）看分配的 `IP 地址：192.168.x.x`，或直接用 `esp32.local`
5. 把 IP 填到电脑端程序 → 文字驱动器页签 → 主机(IP)，端口 **8085**，发送方式 **tcp**

> **重新配网**（换 WiFi / 改密码）：按住板子上的 **BOOT** 键再上电，就会重新进入配网模式。
> 可修改的常量都在文件顶部：`DEVICE_ID` 设备号、`AP_SSID` 热点名、`AP_PASS` 热点密码（默认无密码）、`switch_pins` 引脚、`RELAY_ACTIVE_LOW` 高低电平触发。

## 接线

默认 8 路开关（`switch_pins` 数组可改）：

| 开关 | GPIO | 接继电器 IN |
|------|------|------------|
| 1 | 32 | IN1 |
| 2 | 33 | IN2 |
| 3 | 25 | IN3 |
| 4 | 26 | IN4 |
| 5 | 27 | IN5 |
| 6 | 14 | IN6 |
| 7 | 13 | IN7 |
| 8 | 21 | IN8 |

- 继电器 VCC 接 **5V**（或 3V3，看模块），GND 接 **GND**
- 继电器模块默认是**低电平触发**（`RELAY_ACTIVE_LOW = true`）；如果是高电平触发的模块，改成 `false`

## 测试

烧录后不用开电脑程序也能测：电脑上开一个终端，输入：

```bat
powershell -Command "(New-Object Net.Sockets.TcpClient('192.168.x.x',8080)).GetStream().Write([Text.Encoding]::UTF8.GetBytes('001001on'))"
```

看串口监视器打印 `收到指令: 001001on` 和 `>> 开关 1 打开`，继电器吸合即成功。
